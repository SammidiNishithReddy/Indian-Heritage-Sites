# 📖 Overview

The **Indian UNESCO Heritage Sites** project is a responsive web application designed to educate users about India's UNESCO World Heritage Sites.

The website provides historical information, beautiful images, and an intuitive interface for exploring India's cultural and natural treasures. It serves as an educational platform while demonstrating modern front-end web development concepts.

---

# ✨ Features

- 🇮🇳 Explore India's UNESCO World Heritage Sites
- 🏛️ Detailed information about each heritage site
- 🗺️ Interactive map built using JavaScript and Leaflet.js
- 📍 Location markers for all UNESCO Heritage Sites
- 🔍 Zoom and pan functionality on the map
- 🖼️ High-quality images for each heritage site
- 📱 Responsive design for desktop and mobile devices
- 📝 User Sign-Up page
- 🌐 Easy navigation across multiple pages
- ⚡ Dynamic map interactions powered by JavaScript
